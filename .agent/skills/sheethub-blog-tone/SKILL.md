# SheetHub Blog Writing Tone & Style Guide

This skill defines the writing standard for all SheetHub blog articles — ensuring every post is clear, practical, expert yet approachable, and focused on spreadsheet mastery (Excel & Google Sheets).

---

## 1. Core Principles

- **Clear & Practical:** Get straight to the point with step-by-step instructions and clear formula syntax.
- **Expert & Reliable:** Provide exact formula examples, edge cases, and real-world spreadsheet solutions.
- **Engaging & Human:** Write in a friendly, conversational tone with active voice.
- **English-Only:** All articles on SheetHub are written in English.

---

## 2. Article Structure

Every SheetHub tutorial or guide should follow this logical flow:

1. **Catchy Title & Intro:** Clearly state the problem the reader is trying to solve.
2. **Formula / Concept Overview:** Explain how the function works simply.
3. **Step-by-Step Examples:** Real-world scenarios with syntax code blocks and explanations.
4. **Common Errors & Troubleshooting:** E.g., `#N/A`, `#VALUE!`, or circular reference fixes.
5. **SheetHub's Take (Key Takeaways):** A brief, human summary wrapping up best practices.

---

## 3. Formatting Standards

- Use MDX code blocks with syntax highlighting for formulas:
  ```excel
  =XLOOKUP(lookup_value, lookup_array, return_array, [if_not_found])
  ```
- Use `<Callout variant="info" title="...">` for pro-tips and warnings.
- Headings: Use `##` for main sections and `###` for sub-sections.
