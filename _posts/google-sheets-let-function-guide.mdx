## 2. What Is LET?

- Sintaks: `=LET(name1, value1, [name2, value2, ...], calculation)`
- Variabel bernama di dalam formula
- Availability: Google Sheets (native 2022, semua akun)
- Benefit: readability + performa (evaluasi sekali)

## 3. LET Basics — Named Variables

- `=LET(total, SUM(A1:A10), total * 1.1)` — hitung sekali, pakai berulang
- Contoh nyata: kalkulasi pajak dengan rate sebagai variabel

## 4. LET + FILTER — The Official Pattern

- Contoh resmi Google: `=LET(criteria, FILTER(A2:A, B2:B="Yes"), SUM(criteria))` (ilustrasi — verifikasi sintaks persis saat draft)
- FILTER + ISBLANK pattern
- Kenapa LET di sini: criteria dipakai beberapa kali tanpa duplikasi

## 5. LET + ARRAYFORMULA

- `=LET(data, A2:C100, ARRAYFORMULA(data * 2))`
- Kombinasi dengan MAP/BYROW untuk transformasi per-baris

## 6. 🧠 Fix Missing Headers in Array Filter (Ide User U2)

- Masalah: saat FILTER array, baris header ikut terfilter / hilang dari output
- Pattern SEQUENCE+ROWS: `=LET(rows_count, ROWS(data), ...)` — bangun ulang header + data
- Contoh: `=LET(d, A2:C100, h, A1:C1, VSTACK(h, FILTER(d, ...)))` — header eksplisit + data terfilter
- ⚠️ Uji pattern sebelum publish (GATE SINTAKS) — verifikasi perilaku di Sheets
- Alternatif: ARRAYFORMULA dengan IF untuk header

## 7. Real Use Cases (Tabel)

| Scenario | Solution |
|----------|----------|
| Kriteria dipakai berulang | `=LET(c, B2:B="Yes", FILTER(A2:A, c))` |
| Header hilang saat filter | LET + VSTACK header + FILTER |
| Formula pajak berulang | LET rate + amount |
| Transformasi array | LET data + ARRAYFORMULA |

## 8. Error Handling & Limitations (≥3 poin + workaround)

- Nama variabel bentrok dengan nama range → gunakan nama unik / hindari nama range existing
- LET tidak bisa menyimpan array hasil filter untuk dipakai di luar formula yang sama
- Formula sangat panjang → pecah jadi beberapa LET / Named Functions
- Perilaku LET + array di ARRAYFORMULA perlu uji — verifikasi saat draft
- Paritas Excel: sintaks sama, tapi perilaku array sedikit beda — cross-link, bukan duplikat

## 9. Comparison: LET vs Alternatives

| Method | Pros | Cons |
|--------|------|------|
| LET | Readable, cepat | Butuh pemahaman variabel |
| Named Ranges | Reusable lintas sheet | Setup di Name Manager |
| Formula panjang tanpa LET | Langsung | Sulit dibaca, lambat |

## 10. Pro Tips

- Gunakan LET di semua formula yang punya nilai berulang
- Nama variabel deskriptif (criteria, rate, data) — bukan x, y
- Kombinasikan dengan LAMBDA/Named Functions untuk fungsi custom

## 11. Common Mistakes to Avoid

- Nama variabel sama dengan nama kolom/range
- Lupa argumen calculation terakhir
- Mengira LET menyimpan hasil untuk formula lain (tidak — scope lokal)
