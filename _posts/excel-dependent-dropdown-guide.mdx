A dependent dropdown list in Excel can follow two very different designs. The older approach uses named ranges and `INDIRECT`: it works across a wide range of Excel versions, but it is sensitive to naming mistakes. The newer approach filters a source table into a spill range and points Data Validation at that result: it updates more naturally, but requires dynamic-array support.

Both methods solve the same problem. Choose a country, and the next dropdown shows only its regions. Choose a region, and a third dropdown shows only its cities. The right choice depends on the Excel versions that open the workbook and how often the source list changes.

## What Is a Dependent Dropdown?

A regular dropdown always shows the same list. A dependent dropdown changes its list according to an earlier selection. Common examples include:

- Country → state or province → city
- Department → employee → project
- Category → product → product variant

The first selection is the parent value. The next list uses that value as a filter. If the user chooses `Canada` in cell A2, the dropdown in B2 should not show every region in the workbook. It should show only Canadian regions.

If data validation is new to the workbook, review the basic concepts first: list sources, input messages, error alerts, and validation rules all still apply. The cascade only changes how the source list is generated.

## Method 1: INDIRECT and Named Ranges

The legacy method is useful when the workbook must work in older Excel versions or when the source lists are small and stable.

### Step 1: Create a named range for each parent value

Suppose the first dropdown in A2 contains `NorthAmerica` or `Europe`. Create a named range for each matching child list:

- `NorthAmerica` refers to the regions Canada, United States, and Mexico
- `Europe` refers to the regions France, Germany, and Spain

The name must follow Excel's naming rules. It cannot contain spaces, so use names such as `NorthAmerica` rather than `North America`, or create a consistent name-mapping layer.

### Step 2: Create the parent dropdown

Set Data Validation for A2 to **List** and use a source such as:

```excel
NorthAmerica,Europe
```

For a maintainable workbook, put the parent values in cells and reference that range instead of typing the list directly.

### Step 3: Point the child dropdown to the selected name

Select B2, open **Data** → **Data Validation**, choose **List**, and set Source to:

```excel
=INDIRECT($A$2)
```

When A2 contains `NorthAmerica`, Excel evaluates `INDIRECT($A$2)` as a reference to the named range `NorthAmerica`. When A2 changes to `Europe`, the source list changes with it.

This method is available in older Excel versions, including versions without dynamic arrays. Its main weakness is fragility. A renamed range, a spelling difference, or a parent label that does not exactly match a range name produces `#REF!` or an empty dropdown.

## Method 2: Dynamic Arrays and Spill References

The modern method keeps the source data in one structured table and generates each child list with `FILTER` and `UNIQUE`. It is easier to maintain when new locations are added, provided the workbook is opened in Microsoft 365 or Excel 2021 and later versions that support dynamic arrays.

Assume an Excel Table named `tblLocations` has these columns:

| Country | Region | City |
|---|---|---|
| Canada | Ontario | Toronto |
| Canada | Quebec | Montreal |
| United States | Texas | Austin |
| United States | Washington | Seattle |

Put the selected country in A2. In a helper cell such as E4, generate the region list:

```excel
=SORT(UNIQUE(FILTER(tblLocations[Region], tblLocations[Country]=$A$2, "No matching regions")))
```

The results spill down from E4. Select B2, choose **List** in Data Validation, and use the spill reference as Source:

```excel
=$E$4#
```

The `#` operator means the entire spill range beginning at E4. If the selected country changes, the formula recalculates and the dropdown reads the new result. If more rows are added to `tblLocations`, the table reference expands automatically.

This pattern is closely related to [Excel dynamic array functions](/blog/excel-dynamic-array-functions-guide), especially `FILTER`, `UNIQUE`, and spill behavior. For a deeper explanation of the `#` reference itself, see the [Excel spill ranges guide](/blog/excel-spill-ranges-guide).

### Keep the helper result clean

Place helper formulas on a separate worksheet or in columns beyond the visible form. Give each helper cell a clear label and protect the helper area if other users will enter data in the workbook. Do not place anything below a spill formula: any occupied cell in its path causes `#SPILL!`.

## Building a Three-Level Cascade

A three-level form repeats the same pattern:

1. A2 contains the selected country.
2. B2 contains the selected region.
3. C2 contains the selected city.

For the modern method, generate the region list in E4 and the city list in F4:

```excel
=SORT(UNIQUE(FILTER(tblLocations[Region], tblLocations[Country]=$A$2, "No matching regions")))
```

```excel
=SORT(UNIQUE(FILTER(tblLocations[City], (tblLocations[Country]=$A$2)*(tblLocations[Region]=$B$2), "No matching cities")))
```

Use `=$E$4#` as the Source for B2 and `=$F$4#` as the Source for C2. The multiplication operator combines the two TRUE/FALSE tests as AND logic: the city must belong to the selected country and the selected region.

For older workbooks, create named ranges for every region or city group and repeat the `INDIRECT` pattern. A hybrid design is also possible: use named ranges for the first dependency and a spill formula for a later level, but document the version requirements clearly.

## Legacy or Modern: Which Method Should You Use?

| Decision factor | INDIRECT and named ranges | Dynamic arrays and spill references |
|---|---|---|
| Compatibility | Works across older Excel versions | Requires dynamic-array support |
| Source maintenance | Manual range and name maintenance | Excel Table expands with new rows |
| Rename risk | High if labels and names diverge | Lower because formulas filter values |
| Setup | Simple for a few fixed lists | Better for one normalized source table |
| Best fit | Shared legacy workbooks | Microsoft 365 or Excel 2021+ teams |

Choose `INDIRECT` when compatibility is the priority and the lists rarely change. Choose dynamic arrays when the source is tabular, the list grows regularly, and every user has a supported Excel version.

## Common Errors and Fixes

### The dropdown is empty

With the modern method, check whether `FILTER` found a match. The fallback text in the third argument helps reveal a missing country or region. Also check that the helper spill area is not blocked by existing values.

### `INDIRECT` returns `#REF!`

Compare the selected text with the named range character by character. Spaces, punctuation, and spelling must match. Open **Formulas** → **Name Manager** to confirm that the name exists and refers to the intended cells.

### The city list shows every city

The city formula needs both criteria. Confirm that the country test references A2 and the region test references B2, and that the two ranges have matching row counts.

### The old child selection remains after the parent changes

Changing A2 does not automatically erase an existing value in B2 or C2. Add a validation check, clear dependent cells when the parent changes, or use a small worksheet event in a controlled macro-enabled workbook. At minimum, instruct users to reselect each lower-level dropdown after changing its parent.

### The list does not refresh

Confirm that the Source points to the spill anchor with `#`, not just to a fixed cell. For table-based formulas, verify that the records are inside `tblLocations` and that calculation is set to Automatic.

## Practical Tips

- Keep the source table normalized: one country, region, and city per row.
- Use stable IDs behind display labels when names can change.
- Put helper formulas on a dedicated worksheet and protect it from accidental edits.
- Test the form with a parent that has no matches, one match, and many matches.
- Document the minimum Excel version beside the form.
- Use structured table references so new source rows are included automatically. The [Excel Tables structured references guide](/blog/excel-tables-structured-references-guide) covers that expansion pattern.

## FAQ

**Can a dependent dropdown have four or more levels?** Yes. Repeat the pattern for each level. More levels increase the need for clear helper formulas, reset logic, and testing.

**Does the modern method work in every Excel version?** No. `FILTER`, `UNIQUE`, and spill references require dynamic-array support. Use named ranges and `INDIRECT` when older versions must open the workbook.

**Why does `INDIRECT` break after a rename?** It interprets text as a reference. If the text no longer matches a named range, the reference becomes invalid. Keep display labels and technical names separate when renaming is likely.

**Can the same design be used in Google Sheets?** The concept is similar, but the Data Validation interface and formula behavior differ. Test the implementation separately rather than copying the Excel Source reference unchanged.

## Summary

A dependent dropdown list in Excel can use universal named ranges with `INDIRECT` or modern `FILTER` and `UNIQUE` formulas with a spill reference. The first method favors compatibility; the second favors automatic maintenance from a structured source table. Choose one deliberately, test empty and renamed values, and document the Excel version required by the form.
