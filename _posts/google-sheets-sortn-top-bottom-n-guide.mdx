Filtering a large dataset to isolate the top 5 highest sales or bottom 3 lowest performers usually requires nesting multiple sort and query commands. The **Google Sheets SORTN** function streamlines this by sorting your dataset and returning exactly N rows in a single step, complete with native controls for duplicate ties and grouping rules.

Instead of writing verbose SQL-like syntax in the [QUERY function](/blog/query-function-google-sheets-guide), `SORTN` offers a lightweight, high-performance solution for dashboard widgets and executive summaries.

## What is SORTN and how does it work?

`SORTN` evaluates an array, sorts it across one or more columns, and returns a trimmed subset consisting of the first `n` records according to specified tie-handling behavior.

### Syntax

```excel
=SORTN(range, [n], [display_ties_mode], [sort_column], [is_ascending], ...)
```

- **range**: The source data table to sort and trim.
- **n**: *(Optional, default 1)* The maximum number of rows to return.
- **display_ties_mode**: *(Optional, default 0)* Controls how duplicate values at cutoff boundaries are handled:
  - `0`: Show at most `n` rows, dropping ties beyond `n`.
  - `1`: Show at most `n` rows plus any duplicates tied with the nth row.
  - `2`: Show at most `n` rows after removing duplicate rows entirely.
  - `3`: Show at most `n` unique values, including all records tied to those unique values.
- **sort_column**: The column index (1-based) to sort by.
- **is_ascending**: `TRUE` for ascending (smallest first), `FALSE` for descending (largest first).

Pairing this with the [UNIQUE function](/blog/google-sheets-unique-function-guide) provides deep control over granular reporting tables.

## Pattern 1: Extract the top 5 sales transactions

Suppose sales records with Rep Name, Region, and Amount are located in `A2:C100`. To extract the 5 highest deals without manual filtering:

```excel
=SORTN(A2:C100, 5, 0, 3, FALSE)
```

### How this works:
1. `A2:C100` is the input dataset.
2. `5` requests the top 5 rows.
3. `0` enforces a strict 5-row maximum cut.
4. `3` indicates sorting by the 3rd column (Amount).
5. `FALSE` sorts in descending order (highest revenue first).

## Pattern 2: Top performers including duplicate ties (Fair Leaderboard)

If the 5th and 6th reps scored identical revenue numbers, cutting off strictly at 5 rows creates arbitrary exclusions. Use tie-mode `1` to include all tied runners-up:

```excel
=SORTN(FILTER(A2:C100, B2:B100="West"), 5, 1, 3, FALSE)
```

### How this works:
1. `FILTER` subsets the data to only the "West" region using [flexible criteria](/blog/google-sheets-filter-optional-criteria-guide).
2. `SORTN` sorts the filtered region by column 3 descending.
3. `1` ensures that if multiple reps tie for the 5th spot, all tied reps are returned, preserving complete fairness.

## Troubleshooting and common errors

| Error / Symptom | Root Cause | Practical Fix |
|---|---|---|
| `#REF!` error | The output spill range overlaps existing content below or to the right. | Clear cells around the formula cell to provide room for array expansion. |
| Inaccurate column sort | The `sort_column` number exceeds the total columns in `range`. | Pass a 1-based index corresponding strictly to the input range width. |
| Text numbers sorting incorrectly | Number columns formatted as plain text sort alphabetically (`"100"` before `"20"`). | Convert text values to true numbers before sorting. |

## Summary

`SORTN` eliminates multi-step sorting formulas when extracting top performers or threshold records. Choose tie mode `1` for fair leaderboard reporting and mode `0` for fixed-height dashboard widgets.
