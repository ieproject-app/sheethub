Copilot di Excel menjawab pertanyaan — tapi dari model mana? Jawabannya dikutip dari sumber apa? Juli 2026 menjawab keduanya: pilih model sendiri dan lihat inline citations.

## Copilot Model Choice — Pick Your Model

- Auto (default) / GPT-5.6 / Claude Opus 5
- Cara ganti model di panel Copilot
- Implikasi: pengguna bisa pilih model yang paling cocok untuk jenis tugas
- ⚠️ Verifikasi nama model saat draft (berubah cepat)

### How to Change Your Copilot Model

1. Buka panel Copilot di Excel (Home tab atau dengan shortcut <Kbd>Alt</Kbd> + <Kbd>Shift</Kbd> + <Kbd>C</Kbd>)
2. Klik ikon gear/settings di sudut kanan bawah panel
3. Pilih "Model preference" dari menu dropdown
4. Pilih antara Auto, GPT-5.6, atau Claude Opus 5
5. Konfirmasi pilihan Anda

### When to Choose Which Model

- **Auto (default)**: Microsoft akan memilih model terbaik berdasarkan tugas Anda
- **GPT-5.6**: Lebih baik untuk analisis data kompleks dan rumus rumit
- **Claude Opus 5**: Ungul untuk penulisan naratif, penjelasan langkah-demi-langkah, dan kreasi konten

## Inline Citations — See the Source

- Copilot kini menampilkan sumber inline saat menjawab
- Implikasi: verifikasi lebih mudah, hasil lebih trustworthy

### How Inline Citations Work

Ketika Copilot memberikan jawaban, ia akan menyertakan referensi langsung ke sumbernya dalam format:
```
Menurut Microsoft Support [1], fungsi XLOOKUP diperkenalkan pada 2019...
```
Di mana angka dalam kurung sususunan [1], [2], dll sesuai dengan daftar referensi di akhir respons.

Contoh nyata:
> Untuk menghitung tarif progresif dengan banyak bracket, Anda bisa menggunakan SUMPRODUCT dengan array kondisi [1][2].

Referensi:
1. Microsoft Excel Support: "SUMPRODUCT function"
2. ExcelJet: "Calculate income tax with progressive rates"

### Manfaat Inline Citations

- **Verifikasi cepat**: Tidak perlu mencari sumber secara manual
- **Transparansi**: Tahu dari mana informasi berasal
- **Kepercayaan**: Lebih mudah mempercayai jawaban yang bersumber
- **Pembelajaran**: Buka sumber untuk belajar lebih dalam

## Brand Kit (@brand-kit) & Theme Design (@theme-design)

- Format otomatis sesuai brand kit perusahaan
- Theme design untuk tampilan konsisten
- Implikasi: laporan yang langsung on-brand tanpa styling manual

### Menggunakan @brand-kit Skill

1. Pastikan brand kit perusahaan telah diunggah ke Microsoft 365 admin center
2. Di Excel, ketik `@brand-kit` dalam sel apa saja
3. Copilot akan menampilkan opsi brand yang tersedia
4. Pilih brand yang sesuai dan tekan Enter
5. Sel akan otomatis diterapkan dengan:
   - Font perusahaan
   - Warna tema
   - Gaya borde
   - Format angka khusus (jika dikonfigurasi)

### Menggunakan @theme-design Skill

Sama seperti @brand-kit tetapi fokus pada desain visual:
- Tema warna yang koordinasi
- Gaya grafik yang konsisten
- Template laporan yang siap pakai

Contoh penggunaan:
```
@theme-design corporate-modern
```
akan menerapkan tema coroporate modern ke seluruh workbook.

## AutoSave-Off Support

- Copilot kini bekerja untuk file dengan AutoSave dimatikan
- Implikasi: workflow lokal tanpa cloud tetap bisa pakai Copilot

### Kapan Menggunakan AutoSave Off?

- Bekerja dengan file sensitif yang tidak boleh disimpan ke cloud
- Lingkungan dengan koneksi internet tidak stabil
- Kebidanan perusahaan yang melarang penyimpanan dokumen di layanan publik
- Bekerja pada file besar yang menyinkronkan lambat

### Batasan saat AutoSave Off

- Beberapa fitur kolaborasi real-time tidak tersedia
- Histori versi tidak disimpan secara otomatis
- Perlu menyimpan file secara manual untuk mengupdate perubahan
