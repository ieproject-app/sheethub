Type `1200` into a cell and it looks like 1200. Change the number format to `$#,##0.00` and the same cell reads `$1,200.00`. Switch the format to `0.0,, "M"` and it shows `1.2M`. The value never changed — the formula bar still says 1200. Only the display changed. That is the whole idea behind Excel custom number formats: a format code is a small language that controls how a number looks without altering the number itself.

## Same Number, Three Looks

Here is the same underlying value presented three ways:

| Value in cell | Format code | What you see |
|---------------|-------------|--------------|
| 1200 | `General` | `1200` |
| 1200 | `$#,##0.00` | `$1,200.00` |
| 1200 | `0.0,, "M"` | `1.2M` |

Same cell, same number, three different stories — and switching between them takes seconds.

## What Is a Custom Number Format?

A custom number format is a text string you type into the Format Cells dialog: select the cells, press <Kbd>Ctrl</Kbd> + <Kbd>1</Kbd> — the same shortcut from the [Excel keyboard shortcuts guide](/blog/excel-keyboard-shortcuts-guide) — open the Number tab, choose Custom, and type your code into the Type box. The preview shows the effect before you apply it.

The code only affects display — the stored value and every formula that references the cell stay untouched.

## The Four-Section Structure

Format codes can hold up to four sections, separated by semicolons:

```excel
positive;negative;zero;text
```

Each section handles one case:

| Section | Applies to |
|---------|------------|
| 1st | Positive numbers |
| 2nd | Negative numbers |
| 3rd | Zero |
| 4th | Text entries |

A practical four-section code:

```excel
0.00;[Red]-0.00;0;"n/a"
```

Positive values show two decimals, negatives red with a minus sign, zero as `0`, and text entries as `n/a`.

Fewer sections are fine: one applies to every number, two split positive-and-zero from negative, three add a zero case. Text shows as typed unless a fourth section exists.

## Placeholders: 0, #, and ?

The digits in a format code are placeholders with different levels of commitment:

| Code | Behavior |
|------|----------|
| `0` | Required digit — a missing position shows as 0 |
| `#` | Optional digit — disappears when there is nothing to show |
| `?` | Optional digit that leaves a space, aligning decimals |
| `#,##0` | Thousands separator |

`0` forces a digit: `000` turns `7` into `007`. `#` shows only existing digits: `###` leaves `7` as `7`. `?` pads with spaces, aligning decimals in a column.

## Scaling Large Numbers

A trailing comma scales the value down by one thousand per comma:

```excel
#,##0,
```

`1200` becomes `1` (thousands). A second comma moves into millions:

```excel
#,##0,,
```

`1,200,000` becomes `1`, and `0.0,,` turns `1,200,000` into `1.2`. Full values stay in the cells while the report shows tidy K and M numbers.

## Colors and Conditions

Colors go in square brackets at the start of a section — eight named colors: `[Black]`, `[Blue]`, `[Cyan]`, `[Green]`, `[Magenta]`, `[Red]`, `[White]`, and `[Yellow]`. The classic red-negative format is:

```excel
0.00;[Red]-0.00
```

Conditions use a comparison in brackets with a two-section layout — the first wins when true, the second handles everything else:

```excel
[>100][Green]0;[<=100][Red]0
```

Above 100 displays in green; at or below 100 in red. With conditions, sections mean "true;otherwise", not positive/negative.

## Percent, Scientific & Text

Percent formats multiply the display by 100 and add the symbol:

```excel
0.0%
```

`0.125` shows as `12.5%`. Scientific notation uses the exponent pattern:

```excel
0.00E+00
```

`1200` shows as `1.20E+03`.

Literal text goes in double quotes, and `@` shows whatever text the cell contains. As the fourth section, this formats text entries:

```excel
0.00;[Red]-0.00;0;"Call: "@
```

Type `John` and the cell displays `Call: John`. For a single literal character, escape it with a backslash — `0\K` appends K. `*` (fill) and `_` (space) have special meaning — quote or escape them.

## Custom Dates and Cumulative Time

Date parts combine freely:

```excel
yyyy-mm-dd
```

renders `2026-08-09`; `ddd, mmm d` gives `Sun, Aug 9`. Time is where one character changes everything:

```excel
[h]:mm
```

```excel
h:mm
```

`[h]` counts elapsed hours, so 25 hours and 30 minutes displays as `25:30`. Plain `h` resets at 24, showing `1:30`. Timesheets that cross midnight need the brackets — the most common fix in this topic.

## Real Use Cases

| Need | Format code |
|------|-------------|
| USD with two decimals | `$#,##0.00` |
| Millions with an M label | `#,##0,, "M"` |
| US phone number | `(###) ###-####` |
| Negative values in red | `0.00;[Red]-0.00` |
| Aligned decimal column | `0.0?` |
| Hide the value on screen | `;;;` |

For phone numbers that can start with zero, swap `#` for `0` — `(000) 000-0000` — so leading digits stay visible instead of vanishing.

## Error Handling & Limitations

- **Malformed codes fall back to General.** An invalid code — wrong section count, stray character, unbalanced quotes — silently shows the raw value. Check the preview in Format Cells before applying.
- **Locale changes punctuation.** A comma where your Excel expects a decimal point (or the reverse) is the usual reason a copied code "does nothing."
- **`[h]` vs `h` is easy to mix up.** Durations over 24 hours silently display wrong — decide elapsed vs clock time before writing the code.
- **Format-code conditions are not conditional formatting.** They only handle two numeric comparisons; for formulas, icon sets, or data bars you need conditional formatting rules.
- **Format codes never transform data.** Display-only — use `ROUND` or a helper column when calculations need real rounding.

## Pro Tips

- **Pair codes with conditional formatting.** Number format codes control the static look of a value, while [Excel custom number format codes](/blog/conditional-formatting-guide) change it based on conditions.
- **Build a format library.** Custom formats are stored with the workbook — keep a hidden sheet of your best codes as text.
- **Use `;;;` to hide values.** Three empty sections display nothing while the cell keeps its value.
- **Scale before you style.** Apply `0.0,,` to revenue columns first, then decide on the K/M label.

## Common Mistakes to Avoid

- **Forgetting the semicolons.** Mixing conditions or colors with the wrong number of sections silently produces garbage.
- **Using format codes to round data.** Formulas still read the full-precision value — use `ROUND` when a rounded result matters.
- **Assuming `0.0` rounds the value.** It only rounds the display.
- **Copying codes across locales without checking separators.** A code can fail silently on another machine.
- **Expecting text formatting from a numeric code.** Without a fourth section, text entries ignore your code and show as typed.

## FAQ

**Why doesn't my format show up?** Check the Format Cells preview, verify the separator matches your locale, and confirm the code is on the right cells.

**Can a number format change the value?** No. Formats affect display only; to change the actual data, use formulas.

**How do I show negatives in red?** Use two sections: `0.00;[Red]-0.00`.

**How do I display millions as 1.2M?** Use the double-comma scale: `#,##0.0,, "M"`.

**Availability:** Custom number formats exist in every Excel version — desktop, web, and mobile. Microsoft 365 includes the same codes.

## Summary

Custom number formats are the fastest way to make a spreadsheet look deliberate: the same value can read as `$1,200.00`, `1.2K`, or `1.20E+03` without a single formula. Learn the four-section structure, remember that `0` forces digits while `#` lets them go, and keep `[h]:mm` for anything that crosses midnight.
